# 前端架构模式总结（Code-Behind / MVC / MVP / MVVM / MVVM-C）

> 
> 适用：WPF / MAUI / WinForms / [ASP.NET](https://ASP.NET) Core，面试背诵版

## 1. Code-Behind（代码隐藏）

> 
### WPF 原生写法，XAML + `xxx.xaml.cs` 后台文件，MVVM 的对立面

- 原理：`x:Class` 将 XAML 和后台 partial 类绑定
- 特点：通过 `x:Name` 获取控件，直接操作控件属性、注册事件；业务逻辑和 UI 混在一起
- 优点：简单上手，适合小型弹窗、简单工具、UI 动画特效
- 缺点：耦合高，难以单元测试，逻辑复用差
- 示例

```
<!-- MainWindow.xaml -->
<Window x:Class="Demo.MainWindow">
    <StackPanel Orientation="Horizontal">
        <Button x:Name="btnTest" Click="btnTest_Click" Content="点击"/>
        <TextBlock x:Name="txtMsg"/>
    </StackPanel>
</Window>
```

```
// MainWindow.xaml.cs
public partial class MainWindow : Window
{
    public MainWindow()
    {
        InitializeComponent();
    }
    private void btnTest_Click(object sender, RoutedEventArgs e)
    {
        txtMsg.Text = "按钮点击";
    }
}
```

> 
> 规范：MVVM 项目中，**业务逻辑禁止放 Code-Behind**；仅纯 UI 相关逻辑（焦点、动画、控件特有行为）可保留。

## 2. MVC（Model-View-Controller）
### MVC（Model-View-Controller）

- 角色
  - Model：数据实体、业务、数据访问
  - View：页面渲染（Razor/HTML）
  - Controller：中间人，接收请求，调用 Model，传递数据给 View
- 流向：用户请求 → Controller → Model → Controller 把数据交给 View → View 渲染
- 特点：View 可以感知 Model；Controller 调度；**无自动绑定**
- 适用：[ASP.NET](https://ASP.NET) Core MVC Web 项目

```
// Model
public class User { public int Id { get; set; } public string Name { get; set; } }

// Controller
public class UserController : Controller
{
    public IActionResult Index()
    {
        var user = new User { Id = 1, Name = "张三" };
        return View(user);
    }
}
```

```
@model User
<h1>@Model.Name</h1>
```

## 3. MVP（Model-View-Presenter）
### 3. MVP（Model-View-Presenter）
- 角色
  - Model：数据与业务
  - View：视图，**实现 IView 接口**，只负责暴露 UI 操作方法
  - Presenter：中间人，持有 IView 接口，不直接依赖具体控件
- 流向：用户操作 → View → Presenter → Model → Presenter 调用 IView 接口更新 UI
- 特点：View 和 Model 完全隔离；手动调用接口刷新 UI，**没有自动绑定**，极易单元测试
- 适用：老 WinForms、早期安卓客户端

```
// View接口
public interface IMainView
{
    void SetMessage(string msg);
}

// Model
public class UserModel
{
    public string GetText() => "Hello MVP";
}

// Presenter
public class MainPresenter
{
    private readonly IMainView _view;
    private readonly UserModel _model = new();
    public MainPresenter(IMainView view) => _view = view;
    public void OnClick()
    {
        var text = _model.GetText();
        _view.SetMessage(text);
    }
}

// View
public partial class MainWindow : Window, IMainView
{
    private readonly MainPresenter _presenter;
    public MainWindow()
    {
        InitializeComponent();
        _presenter = new MainPresenter(this);
    }
    private void Button_Click(object sender, RoutedEventArgs e)
    {
        _presenter.OnClick();
    }
    public void SetMessage(string msg)
    {
        txtMsg.Text = msg;
    }
}
```

## 4. MVVM（Model-View-ViewModel）【WPF 主流】
### 4. MVVM（Model-View-ViewModel）【WPF 主流】
- 角色
  - Model：纯数据实体
  - View：XAML 界面，只做展示
  - ViewModel：属性、Command、状态，实现通知接口 `INotifyPropertyChanged`
- 流向：View 通过 `DataContext` 绑定 ViewModel；依靠 Binding 双向自动同步，Command 处理交互
- 特点：ViewModel**不引用任何 UI 控件**；自动绑定，解耦好，方便单元测试
- 适用：WPF、MAUI、UWP

```
// Model
public class User
{
    public string Name { get; set; }
}

// ViewModel（使用CommunityToolkit.Mvvm）
using CommunityToolkit.Mvvm.ComponentModel;
using CommunityToolkit.Mvvm.Input;

[ObservableObject]
public partial class MainViewModel
{
    [ObservableProperty]
    private string _message = "Hello MVVM";

    [ObservableProperty]
    private User _user = new User { Name = "小明" };

    [RelayCommand]
    private void Click()
    {
        Message = "按钮点击了";
    }
}
```

```
<Window.DataContext>
    <local:MainViewModel />
</Window.DataContext>
<StackPanel Orientation="Horizontal" Spacing="10">
    <TextBlock Text="{Binding Message}"/>
    <Button Content="点我" Command="{Binding ClickCommand}"/>
    <TextBlock Text="{Binding User.Name}"/>
</StackPanel>
```

## 5. MVVM-C（也常被叫做 MVVC）
### 5. MVVM-C（也常被叫做 MVVC）
> 
> MVVM 的扩展，增加 Coordinator（协调器 / Controller）

- 角色：Model + View + ViewModel + Coordinator
- 职责拆分
  - ViewModel：只管理当前页面的数据、命令，**不处理导航跳转**
  - Coordinator：专门负责窗口创建、页面导航、模块调度
- 适用：页面多、导航复杂的大型 WPF 上位机项目

```
// Coordinator 导航调度
public class PageCoordinator
{
    public void OpenUserPage()
    {
        var vm = new UserViewModel();
        var win = new UserWindow { DataContext = vm };
        win.Show();
    }
}
```

## 对比总表（面试背诵）
### 对比总表（面试背诵）
表格

| 模式 | 中间人 | 通信方式 | View 能否直接访问 Model | 核心特点 | 典型场景 |
| --- | --- | --- | --- | --- | --- |
| Code-Behind | 无 | 直接操作控件 | 可以 | 逻辑写在后台，耦合高 | 简单弹窗、UI 特效 |
| MVC | Controller | Controller 推送数据 | ✅ 可以 | View 知道 Model | [ASP.NET](https://ASP.NET) Core MVC Web |
| MVP | Presenter | Presenter 调用 IView 接口 | ❌ 不可以 | 手动刷新 UI，无绑定 | WinForms、老安卓 |
| MVVM | ViewModel | Binding 自动双向绑定 | ❌ 不可以 | 无控件引用，自动同步 | WPF / MAUI |
| MVVM-C | ViewModel + Coordinator | 绑定 + 协调器调度 | ❌ 不可以 | 分离导航逻辑 | 复杂多页面 WPF 上位机 |

## 一句话速记

- Code-Behind：直接摸控件
- MVC：控制器指挥
- MVP：Presenter 调用接口刷 UI
- MVVM：绑定自动同步
- MVVM-C：MVVM 再加一层导航协调器
